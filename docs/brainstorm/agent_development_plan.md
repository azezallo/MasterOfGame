# План розробки системи агентного ШІ

Це комплексна фіча, яку необхідно розбити на окремі етапи, щоб мінімізувати переробку коду та забезпечити стабільність системи.

## Стратегія розробки
Замість паралельної розробки фронтенду та бекенду, ми зосередимося на створенні фундаменту — інструментів та механізмів обробки даних — перш ніж переходити до реалізації самого циклу агента та інтерфейсу чату.

---

## Етапи розробки

### Етап 1: Інструменти та Інфраструктура (Tools & Infrastructure)
*Ціль: Створити набір функціональних можливостей, якими агент зможе керувати.*

1.  **Tool Definition Schema**: Визначення стандарту опису інструментів (назва, опис, вхідні параметри у форматі JSON Schema).
2.  **Tool Registry & Executor**: Створення механізму на бекенді, де можна реєструвати функції та викликати їх динамічно.
3.  **Domain-Specific Tools**: Реалізація базових інструментів для ігрового світу:
    *   Інвентар (отримати список, додати предмет, змінити кількість).
    *   NPC (отримати дані про NPC, змінити його стан/відношення).
    *   Світ (отримати час, змінити погоду, отримати опис локації).
4.  **Data Access Layer (DAL) Expansion**: Оновлення існуючих репозиторій для швидкого отримання даних, необхідних для інструментів.

### Етап 2: Контекст та Пам'ять (Context & Memory)
*Ціль: Надати агенту доступ до знань про світ та історію.*

1.  **Session Context Retrieval**: Автоматичне підтягування метаданих сесії до запиту.
2.  **Dynamic Data Injection**: Механізм отримання релевантних даних з БД залежно від запиту гравця (пошук по назвах, категоріях тощо).
3.  **Conversation History Management**: Система збереження історії діалогу для підтримки контексту розмови (Short-term memory).

### Етап 3: Агентний цикл (Agentic Loop)
*Ціль: Реалізація "мозку" системи.*

1.  **LLM Provider Integration**: Інтеграція з моделлю (OpenAI, Anthropic тощо) з підтримкою системних промптів.
2.  **Reasoning & Action Loop**: Реалізація циклу, де агент може планувати дії, використовувати інструменти та обробляти результати їх виконання.
3.  **System Prompt Engineering**: Створення складних системних інструкцій для різних типів агентів.

### Етап 4: Фронтенд Чату (Chat UI)
*Ціль: Візуалізація взаємодії.*

1.  **Basic Chat Interface**: Створення вікна чату та поля введення.
2.  **Streaming Responses**: Реалізація потокового виводу тексту від агента.
3.  **Tool Output Visualization**: Візуалізація дій агента (наприклад, "Агент шукає предмети...") у чаті.

### Етап 5: Інтеграція та Полірування
*Ціль: Поєднання всіх частин у єдиний досвід.*

1.  **End-to-End Testing**: Тестування складних сценаріїв взаємодії.
2.  **UX/UI Polish**: Анімації, стани завантаження, адаптивність.
