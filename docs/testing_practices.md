# Практики тестування

## Загальні принципи
- Тести повинні бути швидкими, незалежними та відтворюваними.
- Використовуйте `vitest` як основний інструмент тестування.
- Використовуйте `supertest` для тестування HTTP-ендпоінтів.

## Робота з базою даних у тестах
- **Ізоляція**: Кожен тест повинен використовувати окремі дані або окрему базу даних.
- **Очищення**: Після завершення кожного тестового циклу або тесту тестові бази даних мають бути видалені.
- **Автоматизація**: Налаштуйте механізм автоматичного створення та видалення тимчасових файлів бази даних SQLite під час виконання тестів (наприклад, у `beforeAll` або `afterAll` хуках).

## Використання тестів
- Використовуйте інтеграційні тести для перевірки критичних шляхів (happy paths) та обробки помилок.
- Використовуйте модульні тести для перевірки окремих функцій та сервісів.
