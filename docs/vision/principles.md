# Принципи проєкту

## Філософія розробки
- **Мінімалістичний стек технологій**: Ми віддаємо перевагу використанню вбудованих можливостей React, TypeScript та Node.js перед зверненням до зовнішніх бібліотек.
- **Розподіл відповідальності**: Чіткі кордони між UI-компонентами, управлінням станом та взаємодією з API.
- **Типобезпека (Type Safety)**: Суворе використання TypeScript як на фронтенді, так і на бекенді для забезпечення цілісності даних.
- **Читабельність понад складність**: Код має бути легко підтримуваним і зрозумілим для будь-якого члена команди.

## Стандарти API
- **Консистенційність**: Послідовні правила іменування ендпоінтів та структур відповідей.
- **Обробка помилок**: Стандартизовані формати відповідей помилок.
- **Розробка на основі документації**: Фічі проєктуєvans у `docs/features/specs/` перед їхньою реалізацією.
