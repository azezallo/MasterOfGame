# Етап 5: Експорт та Інтеграція БД

## Мета
Перетворити "сирі" матричні дані генератора у формат, сумісний із `LocationSchema` (`location_data_schema.md`), та підготувати їх до перенесення в `master_of_game_API`.

## Задачі

1. **Трансформація даних**:
   - Конвертація 2D-масивів у плаский масив об'єктів `LocationSchema`.
   - Генерація унікальних `location_id` для кожного тайлу.
   - Виставлення правильних `matrix_coordinates` (x, y, z=0).
   - Заповнення об'єкта `environmental_state` (mana_density, базова погода).

2. **Генерація зв'язків (Transitions / Graph)**:
   - Алгоритм має автоматично створити масив `transitions` для кожної клітинки, посилаючись на сусідні (Північ, Південь, Схід, Захід) з типом переходу `grid_neighbor`.
   - Врахування річок: якщо річка перетинає кордон клітинок, зв'язок може отримати додатковий тип або потребувати "мосту".

3. **Експорт у БД**:
   - (Опціонально) Підключити `better-sqlite3` і написати скрипт, який заливатиме цей згенерований світ у тестовий файл бази даних `world_test.db` у таблицю `locations`.
   
4. **Завершення**:
   - Рефакторинг та підготовка модулів до імпорту в `master_of_game_API`.

## Очікуваний результат
Повністю готова до використання SQLite база даних зі згенерованим світом, який відповідає всім стандартам контракту системи, та набір ізольованих класів-генераторів, готових до переїзду на бекенд.
