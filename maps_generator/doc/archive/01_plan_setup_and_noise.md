# Етап 1: Ініціалізація, кастомний генератор шуму та HTML-візуалізатор

## Мета
Створити фундамент для генератора мап без використання жодних сторонніх залежностей для математики та рендеру. Базовий розмір сітки визначатиметься константами (напр. width: 100, height: 100, але підтримуватимуться і неквадратні розміри, напр. 100x90). Замість бекенд-генерації картинок ми будемо експортувати дані в JSON і візуалізувати їх через локальний HTML-файл, використовуючи DOM-сітку. Це дозволить інтерактивно перемикати шари (layers) та регулювати їх прозорість.

## Задачі

1. **Ініціалізація проекту (Node.js)**:
   - Створення `package.json` та налаштування TypeScript.
   - **Жодних зовнішніх залежностей** (тільки `typescript` та `ts-node` для розробки).

2. **Власний генератор шуму (Perlin / Simplex)**:
   - Реалізація класичного алгоритму шуму (Perlin Noise 2D).
   - Підтримка фрактального броунівського руху (FBM): октави (octaves), збереження (persistence), лакунарність (lacunarity), масштаб (scale). 
   - Розміри карти (ширина/висота) винесені в конфігурацію/змінні.
   - Експорт згенерованої матриці у файл `out/map_data.js` (як валідна JS змінна `const mapData = ...`, щоб уникнути CORS проблем при відкритті локального HTML-файлу).

3. **Інтерактивний HTML-Рендер (Visualizer - DOM Сітка)**:
   - Створення `viewer/index.html` та `viewer/app.js`.
   - Клієнтський скрипт підключає `out/map_data.js` і будує сітку виключно за допомогою DOM-елементів (наприклад, `div` або `table`), розміри якої динамічно зчитуються з `mapData`.
   - Рендер карти висот у вигляді сірого градієнту (від чорного = найнижча точка, до білого = найвища).
   - Закладення архітектури UI для майбутніх шарів (чекбокси для увімкнення/вимкнення шарів, повзунки прозорості).

## Результат Етапу 1
Ми зможемо запустити скрипт, який згенерує масив висот вказаного розміру (наприклад, 100x90). Відкривши `viewer/index.html` у браузері, ми побачимо інтерактивну карту у вигляді DOM-сітки (градієнт від чорного до білого), яка доведе, що наш генератор шуму працює коректно для будь-яких розмірів.
