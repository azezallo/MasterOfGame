# Master of Game: Maps Generator

Цей документ слугує головним довідником по генератору карт (`maps_generator`). Тут описано архітектуру, способи запуску та поточний прогрес.

## Як запускати генератор

1. Переконайтеся, що ви знаходитесь у теці `maps_generator` та встановіть залежності:
```bash
npm install
```
2. Запустіть генерацію:
```bash
npm start
```
Це автоматично скомпілює TypeScript код і виконає генерацію. Процес генерування глобальної карти, а також рендеринг усіх регіональних карт займає певний час. Всі результати (JSON/JS файли даних та зображення) будуть збережені в папку `out/`.

## Як переглядати згенеровані карти (Viewer)

Для перегляду використовуються статичні HTML файли в папці `viewer/`. Ви можете просто відкрити їх у браузері:

- **Глобальна мапа:** Відкрийте `viewer/svg_map.html`.
- **Регіональні мапи:** Клікніть на будь-яку провінцію/королівство на глобальній мапі (вас перенаправить), або відкрийте `viewer/regional_map.html` напряму.
- **Детальний DOM-viewer:** `viewer/index.html`. *Примітка: Він завантажує оригінальні нестиснуті дані (55MB) і створює DOM-елемент для кожного пікселя. Використовуйте лише для дебагу або тестування маленьких карт.*

Усі SVG-viewer'и мають спільну логіку панорамування та масштабування, що міститься у `viewer/lib/panZoom.js`.

## Структура коду (Архітектура)

Кодова база розбита на логічні модулі для легкого масштабування та модифікації.

- `src/index.ts` — Головний оркестратор пайплайну. Послідовно викликає всі шари генерації та зберігає результати.
- `src/config.ts` — Основні параметри генерації (розмір, seed-и, параметри для Noise, тощо). Тут лежить інстанс `MapConfig`.
- `src/types.ts` — Загальні типи даних та інтерфейси (`WorldData`, `BiomeType`, `Settlement`).
- `src/compression.ts` — Логіка багаторівневого "стиснення" логічної матриці для виведення регіональних (5x) та глобальних (10x) карт без перевантаження клієнта.
- `src/math/` — Математичні утиліти:
  - `perlin.ts` — Алгоритм шуму Перліна (FBM).
  - `random.ts` та `utils.ts` — Спільні функції для псевдовипадковості (`pseudoRandom`, `hashRandom`) та обчислень (`distance`).
- `src/layers/` — Окремі шари (етапи) генерації:
  - `elevation.ts` — Карта висот.
  - `temperature.ts` & `moisture.ts` — Кліматична модель.
  - `hydrology.ts` — Річки та озера.
  - `biomes.ts` — Логіка розрахунку біомів.
  - `magic.ts` — Магічний фон та ядра.
  - `political.ts` — Фракції, поселення, дороги (A* алгоритм).
- `src/render/` — Рендеринг зображень через Node Canvas:
  - `mapRenderer.ts` — Відмальовка глобальної карти (розміщення ассетів).
  - `regionalRenderer.ts` — Відмальовка регіональних карт (із підвищеною густиною лісів та об'єктів).
  - `assetLoader.ts` — Завантаження зображень/ассетів.
- `out/` — Згенеровані дані. Директорія додана в `.gitignore`, щоб запобігти комітам гігантських файлів у репозиторій.

## Що було реалізовано раніше (Рівень 2 та Рефакторинг)

1. **Регіональні Мапи (Рівень 2)**: Реалізовано багаторівневе стиснення (10x для глобальної, 5x для регіонів) з роздільним експортом (`map_data.js`, `global_map_data.js`, `region_<id>_data.js`).
2. **Векторні дороги**: Алгоритм A* тепер зберігає точні векторні координати шляху (`roadPaths`), завдяки чому на відрендерених картах дороги виглядають плавно.
3. **Asset Rendering**: Додано підвищену густину дерев для регіонального рівня, виправлено баги з "деревами у воді", додано морських монстрів.
4. **Масштабний рефакторинг**: Знищено God-об'єкти, видалено `any` типи, усунуто дублювання математичних функцій та логіки рендерінгу. Всі біоми суворо типізовані через `BiomeType` enum.

## Наступні кроки для іншого агента (Передача роботи)

Наступне завдання — реалізація переходу на **Рівень 3 (Мапа Провінції)**:
1. Зробити клікабельними SVG-полігони провінцій у файлі `regional_app.js`.
2. При кліку на провінцію має відкриватися новий рівень деталізації (наприклад, `province_map.html`).
3. Використовувати оригінальне джерело істини (`map_data.js` без стиснення) або створити новий, точковий формат стиснення/експорту для рендерингу конкретної провінції.
4. Додати містам, поселенням і ресурсам унікальні механіки для цього рівня масштабу.
