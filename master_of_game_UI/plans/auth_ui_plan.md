# План розробки фронтенд-частини: Авторизація та Реєстрація (Auth)

## Огляд
Реалізація інтерактивного інтерфейсу для реєстрації та входу гравців, використовуючи вже існуючу дизайн-систему проєкту. Пріоритет надається швидкій інтеграції компонентів та забезпеченню зручного користувацького досвіду на мобільних пристроях.

## Етапи виконання

### Етап 1: Інтеграція компонентів дизайн-системи
- [x] Ідентифікувати необхідні компоненти в `master_of_game_UI/src/components/ui/` (кнопки, поля вводу, індикатори завантаження).
- [x] Додати до дизайн-системи лише ті специфічні елементи, яких не вистачає для форми авторизації (Spinner, Modal).
- [x] Переконатися, що всі компоненти відповідають стилістиці "Dark Fantasy".

### Етап 2: Реалізація AuthPopup та форм
- [x] Створити головний компонент `AuthPopup`.
- [x] Реалізувати форму Реєстрації:
    - Використовувати інтегровані компоненти `Input` та `Button`.
    - Додати валідацію полів (мінімальна довжина, збігання паролів) з використанням Zod.
- [x] Реалізувати форму Входу.
- [x] Реалізувати перемикач між режимами "Вхід" та "Реєстрація".
- [x] Створити систему виводу повідомлень про помилки реєстрації/входу.

### Етап 3: API Інтеграція та Управління Станًا
- [x] Інтегрувати API запити до бекенд-ендпоінтів (`/auth/register`, `/auth/login`).
- [x] Реалізувати обробку успішних відповідей: автоматичне закриття попапа та оновлення стану авторизації.
- [x] Інтегрувати отримання даних гравця через `/auth/me` для оновлення UI.
- [x] Реалізувати збереження та читання стану авторизації (куки).

### Етап 4: Адаптивність та Фіналізація
- [ ] Перевірити коректне відображення попапа на мобільних екранах (розміри, доступність кнопок).
- [ ] Виконати фінальний візуальний аудит відповідно до вимог дизайн-системи.

## Критерії прийняття (Acceptance Criteria)
1. Використовуються існуючі компоненти з папки `ui/` замість створення дублікатів.
2. Форма реєстрації валідує дані перед відправкою.
3. Після успішного входу попап закривається, а гра стає доступною.
4. Всі компоненти адаптивні для мобільних пристроїв.
5. Використання CSS Modules для стилізації AuthPopup.
