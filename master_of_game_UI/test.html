Dark Fantasy RPG UI Design System

Класичний середньовічний стиль (Старий пергамент, іржаве залізо та вогонь)

Цей документ містить готову дизайн-систему на чистому HTML/CSS для текстової рольової гри. Всі елементи адаптовані під атмосферу темного середньовіччя з використанням глибоких тіней, ефекту затертого металу, пергаментних вставок та золотавих акцентів багаття.

2. Готовий CSS Код для проєкту

Нижче наведено базові стилі, які ти можеш вставити у свій style.css файл для повної стилізації стандартних HTML-тегів під дарк-фентезі:

/* Головна тема гри */ body { background-color: #120e0a; color: #ddcfba; font-family: 'Georgia', serif; } /* Текстова зона / Пергамент */ .story-zone { background: #ebdcb9; color: #2b1d0c; border: 3px double #6e4f31; padding: 20px; box-shadow: inset 0 0 20px rgba(90,60,30,0.5), 0 4px 15px rgba(0,0,0,0.6); } /* Кнопки з ефектом залізної ковки та полум'я */ .btn-rpg { background: linear-gradient(to bottom, #4a3b2c, #261c12); color: #ebdcb9; border: 1px solid #73593f; padding: 10px 20px; text-transform: uppercase; letter-spacing: 1px; cursor: pointer; transition: all 0.3s ease; } .btn-rpg:hover { border-color: #d1a153; color: #fff; box-shadow: 0 0 10px rgba(209, 161, 83, 0.4); } /* Інпути та Селекти */ input[type="text"], select { background-color: #241b12; color: #f5ebd5; border: 1px solid #5c442e; padding: 10px; box-shadow: inset 0 2px 5px rgba(0,0,0,0.8); } input[type="text"]:focus { border-color: #d1a153; outline: none; } /* Кастомізація Чекбоксів (Базова логіка) */ input[type="checkbox"] { accent-color: #d1a153; }
