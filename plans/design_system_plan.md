# План реалізації фічі: Дизайн-система UI

## Огляд
Створення базової бібліотеки UI-компонентів, що відповідають атмосфері "Dark Fantasy". Мета — створити швидкий, реактивний та портативний інтерфейс з мінімальним використанням зовнішніх бібліотек, використовуючи модульну систему стилізації.

## Етапи виконання

### Етап 1: Налаштування середовища та базових типів (Infrastructure)
- [ ] Визначення глобальних CSS змін (кольори, шрифти, фони) у глобальному файлі стилів.
- [ ] Створення базової структури папок у `master_of_game_UI/src/components/ui/`.
- [ ] Налаштування конфігурації CSS Modules для проєкту.
- [ ] Створення базових типів даних (TypeScript interfaces/Zod schemas) для компонентів.

### Етап 2: Створення базових елементів (Atomic Components)
- [ ] Створення компонентів кнопок (Button):
    - Варіанти: Primary (Золото), Secondary (Залізо), Danger (Вогонь).
    - Стан: Hover, Active, Disabled.
- [ ] Створення полів вводу (Input):
    - Текстові поля, вибір (Select).
    - Стилізація "під пергамент" та "під залізо".
- [ ] Створення елементів вибору:
    - Кастомні чекбокси та радіо-кнопки.
- [ ] Створення системи виводу повідомлень (Message/Dialogue):
    - Візуалізація відповідей ШІ (наприклад, стилізований текст у рамці).
    - Візуалізація вводу гравця (керування діалогом).
- [ ] Використання CSS Modules для інкапсуляції стилів кожного компонента.

### Етап 3: Створення "Вікна Дизайн-Системи" (Design System Popup)
- [ ] Створення сторінки з попапом для демонстрації системи.
- [ ] Розміщення всіх створених елементів у категорії (Buttons, Forms, Info).
- [ ] Виведення статичних прикладів використання повідомлень (гравець/ШІ).

### Етап 4: Тестування та адаптивність
- [ ] Перевірка адаптивності всіх компонентів під мобільні екрани.
- [ ] Перевірка коректності відображення стилів у різних контейнерах.

## Критерії прийняття (Acceptance Criteria)
1. Всі компоненти UI використовують CSS Modules для стилізації.
2. Глобальний фон та шрифти задані в центральному місці.
3. Створені компоненти кнопок, інпутів, чекбоксів та полів повідомлень.
4. Повністю реалізовано вікно дизайну з усіма елементами.
5. Система повністю адаптивна для мобільних пристроїв.
