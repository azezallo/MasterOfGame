### Етап 2: Керування знаннями (Knowledge Management)
*Ціль: Визналити механіку "секретів" та відкриття інформації.*

- [x] **Візуалізація знань**: Визначено (динамічні описи).
- [x] **Поширення знань**: Визначено (через прямі дії гравця/NPC).

### Етап 3: Соціальна мережа та Репутація (Relationship & Reputation)
*Ціль: Описати динаміку соціальних зв'язків.*
- [x] **Матриця відносин**: Визначена (текстові зв'язки).
- [x] **Організаційна лояльність**: Визначена (баланс особистого та фракційного).
- [x] **Динамічні зміни**: Визначено (контекстні зміни).

### Етап 4: Ініціатива та Реактивність (Initiative & Reactivity)
*Ціль: Визначити поведінкову логіку NPC у світі.*
- [x] **Проактивна ініціатива**: Визначено як частина опису сцени Майстром (наприклад, ініціація продавця чи прохожого).

- [x] **Пріоритети дій**: Вирішено архітектурно (відмова від хардкоду ієрархії; Майстер зважує пріоритети динамічно на основі драйверів та прив'язк).

- [x] **Перевірка полів**: Пошук пропущених полів для повної підтримки ініціативи та репутації.
