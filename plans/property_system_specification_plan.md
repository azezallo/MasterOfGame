# План деталізації специфікації системи Майна та Власності (`agent_tools_property.md`)

Цей план описує послідовні етапи проробки специфікації для перейменованої та розширеної фічі **F007: Інструменти Агента: Майно** (замість вузького поняття "Інвентар").
Мета — створити комплексний стандарт володіння майном для персонажів гравців та NPC, що об'єднує рухомі речі (зброю, сумки), фінансові активи, нерухомість на карті світу, транспорт і стаціонарні сховища, а також розробити інструменти ШІ-Майстра для управління ними.

---

## Етапи деталізації

### Етап 1: Концепція та Схема даних майна (`property_data_schema.md`)
*Ціль: Сформувати глобальну структуру власності для будь-якої сутності (гравця чи NPC).*
- [x] **Відмова від простого списку**: Перехід від плоского масиву ID до структурованого профілю власності (`PropertyProfile`).
- [x] **Класифікація активів**: Розділення майна на 6 базових категорій:
  1. `equipped` (Екіпіровані предмети на тілі/в руках).
  2. `pocket_inventory` (Рухомий інвентар / рюкзак із собою).
  3. `finances` (Грошові активи: золоті/срібні/мідні монети, векселі, коштовні папери).
  4. `real_estate` (Нерухомість: власні будинки, кузні, орендовані кімнати в тавернах, земельні ділянки).
  5. `storage_caches` (Стаціонарні сховища: скрині в банку, особисті сховки, тайники).
  6. `vehicles_and_mounts` (Транспорт та їздові тварини: коні, вози, човни з власним вантажним відсіком).
- [x] **Створення схеми**: Написання JSON-схеми `docs/features/specs/property_data_schema.md`.

### Етап 2: Система Екіпірування та Обмеження ваги (Equipment Slots & Weight Limits)
*Ціль: Визначити механіку використання предметів та фізичні обмеження персонажа.*
- [x] **Вільна шарувата система екіпірування**: Деталізація масиву `equipped` із зонами тіла (`body_zone`), шарами надівання (`layer`) та контролем логіки від ШІ-Майстра.
- [x] **Вантажопідйомність і швидке скидання**: Розділення ваги на тілі та ваги рюкзака (`backpack_weight_kg`), два статуси завантаженості (загальний та бойовий) і тул `toggle_backpack`.

### Етап 3: Фінанси, Економіка та Нерухомість (Finances, Real Estate & Economy)
*Ціль: Інтегрувати майно в економіку світу та просторову мапу.*
- [x] **Універсальна валюта та Таблиця базових цін**: Відмова від конвертації монет на користь єдиної валюти (`coins`) та створення еталонної таблиці вартості для ШІ-Майстра і гравця.
- [x] **Володіння нерухомістю (`real_estate`)**: Зв'язок між персонажем і тайлами мапи (`location_id`), статус володіння, витрати на утримання або пасивний дохід від бізнесу.
- [x] **Транспорт і мобільні сховища**: Механіка возів та кораблів, зв'язок зі сховищем і тул `manage_vehicle_status`.

### Етап 4: Інструменти Майстра для управління майном (`agent_tools_property.md`)
*Ціль: Визначити технічний контракт (Function Calling API) для ШІ-Майстра.*
- [x] **Специфікація тулів**: Розробка JSON-схем та опису 7 інструментів:
  1. `get_owner_property(owner_type, owner_id)` — Отримання повного профілю майна гравця або NPC.
  2. `transfer_property(...)` — Універсальна передача майна (предметів, монет, прав власності).
  3. `equip_item(...)` / `unequip_item` — Надівання або знімання спорядження в шари.
  4. `toggle_backpack(...)` — Скидання або піднімання рюкзака в бою.
  5. `modify_finances(owner_id, operation, amount_coins)` — Зміна грошового балансу монет.
  6. `register_real_estate(...)` — Реєстрація права власності або бізнесу на локацію.
  7. `manage_vehicle_status(...)` — Керування станом транспорту (у стайні чи в дорозі).

### Етап 5: Відображення на UI (Frontend Representation — Player UI Only)
*Ціль: Спроектувати зручний інтерфейс майна для гравця.*
- [x] **Екран "Кукла персонажа" та Рюкзак**: Ієрархічний список екіпірування за шарами замість жорстких слотів.
- [x] **Гаманець та Фінансові активи**: Панель відображення балансу монет та боргових розписок.
- [x] **Вкладка "Нерухомість та Транспорт"**: Список власних будинків, орендованих кімнат та їздових тварин з можливістю переглянути їхній вміст чи розташування на карті.

**Всі 5 етапів розробки системи майна (Property System F007) успішно завершено!** Створено гнучку систему екіпірування без жорстких слотів, двоконтурну модель ваги (швидкий скид рюкзака), універсальну валюту з продуманим прайс-листом та інструменти ШІ-Майстра для управління всіма аспектами власності.
